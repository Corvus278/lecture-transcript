# Технический долг — `lecture-transcript-pipeline`

Сюда уходит некритичное и сложное: P2 из аудитов, отложенные улучшения,
непроверяемое в dev-окружении. Критерий попадания — не мешает MVP
(`mp4 → transcript.md` на целевой машине). Подробности решений — в `DECISIONS.md`.

## Design / функциональность

- [ ] **GigaAM не принимает глоссарий** (`gigaam 0.1.0` без hotwords). Сейчас деградация с предупреждением. Кандидат: постобработка — подгонять написание распознанных слов под глоссарий нечётким сопоставлением с сохранением таймкодов. Новый механизм сверх спеки, нужен апрув
- [ ] Порог hamming 43 не проверен для платформ, где смена слайда идёт без провала демонстрации — на эталоне все 44 смены режутся по провалу
- [ ] GigaAM не даёт по-словных таймкодов — слова распределяются внутри куска пропорционально длине

- [ ] Абсолютные пиксельные пороги подобраны на одной записи (1080p) — на другом разрешении не проверены

## slide-ocr — из второго аудита

- [ ] Логотип попадает в глоссарий, если его слова хоть раз встретились вне плашки (приветственный слайд, OCR разбил плашку). На GigaAM безвредно — глоссарий не подаётся; на Whisper занимает начало промпта
- [ ] Однословный заголовок темы, который есть только в шапке («Тригонометрия»), вырезается как оформление
- [ ] Эвристика «рукописное против формулы»: рукописное с `=`/`+`, распознанными OCR, уходит в pix2tex (фрагмент помечается неуверенным)
- [ ] VLM: смешанная строка «текст $формула$» получает `kind="text"`, экранирование ломает inline-LaTeX
- [ ] `confidence_threshold` нельзя понизить ниже 0.6: Paddle-парсер жёстко ставит `low_confidence`, пороги роутинга и рукописного не прокинуты из конфига
- [ ] PaddleX 3.2.0 по умолчанию включает выпрямление документа (`use_doc_unwarping`) — боксы могут не совпасть с PNG, кроп для pix2tex съедет (гипотеза)
- [ ] Смешанная строка одним боксом («Пример 4. √(12−x) = x») целиком уходит в pix2tex, русский текст теряется (гипотеза, зависит от сегментации)
- [ ] Отсечение беглой гласной склеивает разные слова (`сложение/сложный`)
- [ ] Проверка контракта не ловит обязательный keyword-only аргумент и `async recognize`

## warmup

- [ ] Финальная проверка после прогрева слабая: `check_availability()` у pix2tex, пунктуатора, silero и gigaam проверяет только установленные пакеты, а не наличие весов в кэше. Надёжнее — повторить фиктивные загрузки в отдельном процессе с офлайн-режимом. Сама успешная загрузка при прогреве веса скачивает, так что прогон это не блокирует
- [ ] Те же бэкенды при `HF_HUB_OFFLINE=1` без прогрева объявят себя доступными и упадут в середине прогона, а не до старта
