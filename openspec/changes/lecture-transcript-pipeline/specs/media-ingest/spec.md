## Purpose

Приводит входную запись лекции к двум нормализованным потокам — аудио и кадрам видео — чтобы остальные возможности не зависели от контейнера, кодека, частоты дискретизации и раскладки каналов исходного файла.

## ADDED Requirements

### Requirement: Извлечение нормализованного аудио

Система SHALL извлекать из входного медиафайла единую аудиодорожку, приведённую к моно с частотой дискретизации 16 кГц, независимо от исходного количества каналов, кодека и частоты.

#### Scenario: Моно-дорожка на нестандартной частоте

- **WHEN** на вход подан файл с одной аудиодорожкой 48 кГц моно
- **THEN** система выдаёт аудио 16 кГц моно, покрывающее всю длительность записи

#### Scenario: Многоканальная дорожка

- **WHEN** на вход подан файл со стерео- или многоканальной аудиодорожкой
- **THEN** каналы сводятся в моно без потери речевых фрагментов, присутствующих хотя бы в одном канале

#### Scenario: Несколько аудиодорожек

- **WHEN** входной файл содержит более одной аудиодорожки
- **THEN** система использует дорожку, выбранную конфигурацией, а при отсутствии выбора — первую, и сообщает, какая дорожка использована

### Requirement: Извлечение кадров видео

Система SHALL извлекать кадры видеотрека с настраиваемой частотой выборки и сопоставлять каждому кадру его временну́ю метку относительно начала записи.

#### Scenario: Выборка кадров с заданной частотой

- **WHEN** запрошено извлечение кадров с частотой 1 кадр в секунду для записи длительностью 1:31:22
- **THEN** система выдаёт последовательность кадров, каждый с временно́й меткой, покрывающую всю длительность записи

#### Scenario: Точность временны́х меток

- **WHEN** кадр извлечён из позиции записи
- **THEN** его временна́я метка соответствует этой позиции с точностью не хуже интервала выборки

### Requirement: Обработка отсутствующих дорожек

Система SHALL определять состав дорожек входного файла и вести себя предсказуемо при отсутствии любой из них.

#### Scenario: Файл без видеотрека

- **WHEN** входной файл содержит только аудио
- **THEN** пайплайн продолжает работу в аудио-режиме, возможности работы со слайдами пропускаются, и пользователь предупреждён о неполноте результата

#### Scenario: Файл без аудиодорожки

- **WHEN** входной файл не содержит аудиодорожки
- **THEN** система завершается с ошибкой, поскольку транскрипт речи получить невозможно

#### Scenario: Повреждённый или нечитаемый файл

- **WHEN** входной файл не может быть декодирован
- **THEN** система сообщает об ошибке с указанием причины и не создаёт частичных выходных артефактов

### Requirement: Переиспользование промежуточных артефактов

Система SHALL сохранять извлечённые аудио и кадры и переиспользовать их при повторном запуске для того же входного файла с теми же параметрами извлечения.

#### Scenario: Повторный запуск без изменения параметров

- **WHEN** пайплайн запущен повторно для того же файла с теми же параметрами извлечения
- **THEN** этап извлечения переиспользует сохранённые артефакты и не выполняет декодирование заново

#### Scenario: Изменение параметров извлечения

- **WHEN** пайплайн запущен для того же файла с другой частотой выборки кадров
- **THEN** кадры извлекаются заново, а сохранённые артефакты с прежними параметрами не используются
