## Why

Записи академических пар (вебинары 1.5–2 ч) нужно превращать в текст, из которого удобно писать конспект. Готового решения под этот кейс нет: существующие пайплайны (WhisperX, whisper-diarization) дают сырую расшифровку аудио — простыню без структуры, с филлерами и с математикой, записанной словами.

Ключевое наблюдение по эталонной записи (`wr_20260909_1150.mp4`, вебинар по математике, 1:31:22, моно-аудио + видео 1080p): **значимая часть содержания лекции существует только в видеотреке**. Лектор произносит «корень из икс квадрат минус икс равно минус пять», а корректная запись `√(x²−x) = −5` есть лишь на слайде. Конспект по одному аудио для такого предмета получить нельзя — расшифровка аудио без слайдов принципиально неполна.

## What Changes

- Новый локальный пайплайн: `mp4` → `transcript.md`, пригодный как исходник для конспекта.
- Извлечение слайдов из видеотрека: детект области демонстрации, дедупликация состояний слайда, сохранение кропа слайда как PNG.
- Распознавание содержимого слайдов: печатный текст и печатные формулы (в LaTeX). Рукописные пометки маркером **не распознаются** — вместо этого в транскрипт вставляется ссылка на PNG слайда.
- Транскрибация аудио со сменными ASR-бэкендами: GigaAM-v2 (русский, по умолчанию) и Whisper large-v3 (смешанная речь ru+en).
- Двухпроходность: глоссарий терминов, полученный из слайдов, подаётся в ASR как hotwords / `initial_prompt` для снижения ошибок на терминологии.
- Сборка транскрипта по единой оси времени: речь, сгруппированная по слайдам, с таймкодами и врезками содержимого слайда.
- Целевое окружение: WSL2 + Docker на Windows, одна GPU RTX 4060 8 GB. Все модели локальные, без внешних сервисов.

Вне скоупа этой версии (отдельный будущий change):
- Разделение речи по спикерам (детект рамки активного спикера, OCR ФИО участников, акустическая диаризация).
- Генерация самого конспекта LLM — пайплайн заканчивается на `transcript.md`.

## Capabilities

### New Capabilities
- `media-ingest`: приём входного mp4, извлечение аудиодорожки в нормализованный WAV и извлечение кадров видео с заданной частотой; общий вход для аудио- и видео-ветки.
- `slide-extraction`: определение области демонстрации слайдов в кадре, обнаружение отсутствия демонстрации, дедупликация кадров в логические слайды с временными интервалами и выбор репрезентативного кадра.
- `slide-ocr`: распознавание содержимого репрезентативного кадра слайда в Markdown с формулами в LaTeX через сменные локальные бэкенды; формирование глоссария терминов лекции.
- `speech-transcription`: детекция речи, транскрибация аудио через сменные локальные ASR-бэкенды с поддержкой глоссария, восстановление пунктуации и регистра, выдача слов с таймкодами.
- `transcript-assembly`: слияние слайдов и речи по единой оси времени и генерация итогового `transcript.md` в формате, оптимизированном под написание конспекта.

## Impact

**Новый код.** Проект создаётся с нуля, ломать нечего.

**Зависимости (все локальные):**
- `ffmpeg` с nvdec — декодирование видео и извлечение аудио
- `GigaAM-v2` (MIT, ~240M параметров) — ASR для русского
- `faster-whisper` / `large-v3` — ASR для смешанной речи
- `silero-vad` — детекция речи
- модель восстановления пунктуации и регистра для русского
- `PaddleOCR` (ru) — печатный текст слайдов
- `pix2tex` — печатные формулы → LaTeX
- опционально `Qwen2.5-VL` (4bit) — альтернативный OCR-бэкенд одним проходом
- `imagehash` / OpenCV — дедупликация кадров и анализ области слайда

**Ограничения окружения:**
- WSL2 + Docker, CUDA passthrough на Windows
- бюджет VRAM 8 GB → стадии пайплайна выполняются последовательно с выгрузкой моделей между ними
- никаких внешних API: в кадре присутствуют ФИО студентов, обработка остаётся локальной

**Точки расширения, заложенные заранее:** абстракция ASR-бэкенда и абстракция OCR-бэкенда — обе нужны, чтобы менять модель под предмет и язык лекции без переписывания пайплайна.
